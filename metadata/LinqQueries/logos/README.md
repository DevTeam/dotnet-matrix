# Library logos

Two files are the official package icons declared and embedded by the NuGet
packages:

| File | Package | Source |
|---|---|---|
| `zlinq.png` | `ZLinq` 1.5.6 | embedded `Icon.png` |
| `hyperlinq.png` | `NetFabric.Hyperlinq` 3.0.0-beta9 | embedded `Icon.png` |

The remaining files are neutral project-owned marks:

- `struct-linq.svg` — `StructLinq` 0.28.2 declares no icon.
- `linq-af.svg` — `LinqAF` 3.0.0 declares no icon.
- `system-linq.svg` — package-less BCL implementation.
- `hand-coded.svg` — reused project-owned hand-coded mark.

The neutral library marks use a light plate with dark lettering so they remain
legible on light and dark application backgrounds. Names and official icons
remain the property of their respective owners and are used only to identify
the libraries in the comparison UI.
